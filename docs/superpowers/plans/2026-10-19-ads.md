# 광고(AdMob) 도입 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 리텐션을 해치지 않는 선에서 AdMob 배너·전면광고를 넣고, 서버에서 즉시 끌 수 있게 만든다.

**Architecture:** 노출 판정은 순수 함수(`domain/adFrequency`)에 모으고, 저장은 AsyncStorage(`utils/adState`), 설정은 Supabase `app_config` 에서 읽는다. 화면은 `<AdBanner />` 와 `useAds().showInterstitial()` 만 호출하며 광고 SDK 를 직접 알지 못한다. 설정을 못 읽으면 광고를 띄우지 않는다(fail-closed).

**Tech Stack:** React Native 0.79, `react-native-google-mobile-ads`, TanStack Query v5, Supabase, AsyncStorage, Jest.

**Spec:** `docs/superpowers/specs/2026-10-09-ads-design.md`

## Global Constraints

- 광고가 **절대 들어가지 않는 구간**: 운동 중 카운팅, 세트 사이 휴식 타이머, 100개 챌린지 초기·중간·최종 테스트, 로그인/프로필/설정.
- 전면광고 기본값: 일일 2회, 최소 간격 180초, 유예 1회(첫 운동 면제).
- `app_config` 기본값은 **전부 꺼짐**(`ads_enabled=false`, `interstitial_enabled=false`). 조회 실패 시에도 꺼진 값으로 취급한다.
- iOS 는 `requestNonPersonalizedAdsOnly: true` 로 시작한다. ATT 팝업과 `NSUserTrackingUsageDescription` 은 이번 범위 밖.
- 하루 경계는 KST. 기존 `formatKSTDate` (`src/utils/time.ts`)를 재사용한다.
- 광고 로드 실패·미노출이어도 네비게이션은 반드시 진행한다.
- 테스트는 `jest.mock('../../src/lib/supabase', factory)` 패턴을 쓴다(자동 목은 ESM 을 끌어와 실패한다). 검증: `npx jest __tests__/<path>`, `npx tsc --noEmit -p tsconfig.json`, `npx eslint src __tests__`. `__tests__/App.test.tsx` 는 기존부터 깨져 있으므로 전체 `npx jest` 로 판단하지 않는다.
- 커밋 메시지는 한국어, 본문 끝에 `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>` 과 `Claude-Session: https://claude.ai/code/session_015x1wap39gSZJnbs8ajnPCa`.

## Review Focus

- **설정 조회 전 전면광고 호출**: 앱 시작 직후 운동을 끝내면 `app_config` 가 아직 로딩 중이다. 로딩 중에는 광고를 띄우지 않아야 한다 → Task 4.
- **기기 시계를 과거로 돌림**: `lastShownAt` 이 미래가 되어 `now - lastShownAt` 이 음수가 된다. 음수 간격은 "충분히 지나지 않음"으로 취급해야 한다 → Task 1.
- **AsyncStorage 에 깨진 JSON/부분 객체**: 앱이 죽지 않고 초기 상태로 복구해야 한다 → Task 2.
- **날짜만 바뀌고 앱은 계속 떠 있는 경우**: 자정을 넘겨도 `shownToday` 가 리셋되지 않으면 그날 광고가 안 나간다 → Task 1.
- **전면광고가 영영 로드되지 않음**: 사용자가 결과 화면에 갇힌다. 타임아웃 후 네비게이션을 진행해야 한다 → Task 4.

### Task 1: 노출 판정 로직 (domain/adFrequency)

**Files:**
- Create: `src/domain/adFrequency.ts`
- Test: `__tests__/domain/adFrequency.test.ts`

**Interfaces:**
- Produces:
  - `type AdConfig = {adsEnabled: boolean; interstitialEnabled: boolean; dailyCap: number; minGapSeconds: number; graceWorkouts: number}`
  - `type AdState = {date: string; shownToday: number; lastShownAt: number | null; completedWorkouts: number}`
  - `ADS_OFF: AdConfig` — 모든 플래그가 꺼진 기본값 (`dailyCap: 2`, `minGapSeconds: 180`, `graceWorkouts: 1`)
  - `createAdState(now: Date): AdState`
  - `rollDate(state: AdState, now: Date): AdState`
  - `shouldShowInterstitial(config: AdConfig, state: AdState, now: Date): boolean`
  - `recordInterstitialShown(state: AdState, now: Date): AdState`
  - `recordWorkoutCompleted(state: AdState): AdState`

- [ ] **Step 1: 실패하는 테스트 작성**

`__tests__/domain/adFrequency.test.ts` 에 아래 이름과 단언으로 작성한다. `base` 는
`{date: '2026-10-19', shownToday: 0, lastShownAt: null, completedWorkouts: 5}`,
`on` 은 `{...ADS_OFF, adsEnabled: true, interstitialEnabled: true}`,
`now` 는 `new Date('2026-10-19T12:00:00+09:00')` 로 둔다.

```ts
describe('shouldShowInterstitial', () => {
  it('설정이 모두 켜지고 조건을 만족하면 노출한다', () => {
    expect(shouldShowInterstitial(on, base, now)).toBe(true);
  });
  it('ads_enabled 가 꺼져 있으면 노출하지 않는다', () => {
    expect(shouldShowInterstitial({...on, adsEnabled: false}, base, now)).toBe(false);
  });
  it('interstitial_enabled 가 꺼져 있으면 노출하지 않는다', () => {
    expect(shouldShowInterstitial({...on, interstitialEnabled: false}, base, now)).toBe(false);
  });
  it('유예 기간 안이면 노출하지 않는다 (첫 운동 면제)', () => {
    expect(shouldShowInterstitial(on, {...base, completedWorkouts: 1}, now)).toBe(false);
    expect(shouldShowInterstitial(on, {...base, completedWorkouts: 2}, now)).toBe(true);
  });
  it('일일 한도에 도달하면 노출하지 않는다', () => {
    expect(shouldShowInterstitial(on, {...base, shownToday: 2}, now)).toBe(false);
  });
  it('최소 간격이 지나지 않았으면 노출하지 않는다', () => {
    const recent = {...base, shownToday: 1, lastShownAt: now.getTime() - 179_000};
    expect(shouldShowInterstitial(on, recent, now)).toBe(false);
    const old = {...base, shownToday: 1, lastShownAt: now.getTime() - 180_000};
    expect(shouldShowInterstitial(on, old, now)).toBe(true);
  });
  it('기기 시계가 과거로 돌아가 lastShownAt 이 미래여도 노출하지 않는다', () => {
    const future = {...base, shownToday: 1, lastShownAt: now.getTime() + 60_000};
    expect(shouldShowInterstitial(on, future, now)).toBe(false);
  });
});

describe('rollDate', () => {
  it('날짜가 바뀌면 shownToday 와 lastShownAt 을 초기화한다', () => {
    const next = rollDate({date: '2026-10-18', shownToday: 2, lastShownAt: 1, completedWorkouts: 5},
                          new Date('2026-10-19T00:10:00+09:00'));
    expect(next).toEqual({date: '2026-10-19', shownToday: 0, lastShownAt: null, completedWorkouts: 5});
  });
  it('같은 날이면 상태를 그대로 돌려준다', () => {
    const same = {date: '2026-10-19', shownToday: 1, lastShownAt: 10, completedWorkouts: 5};
    expect(rollDate(same, now)).toBe(same);
  });
});

describe('recordInterstitialShown / recordWorkoutCompleted', () => {
  it('노출을 기록하면 횟수와 시각이 갱신된다', () => {
    expect(recordInterstitialShown(base, now)).toMatchObject({shownToday: 1, lastShownAt: now.getTime()});
  });
  it('운동 완료를 기록하면 누적 수가 1 늘어난다', () => {
    expect(recordWorkoutCompleted(base).completedWorkouts).toBe(6);
  });
});
```
